Dies ist ein Gruppenprojekt aus reinem HTML & CSS, im Stil von einem Reiseblog. Hierbei wird gemeinsam eine Landingpage, anhand einer Figmavorlage, erstellt und 
von jedem der Gruppenmitglieder zusätzlich noch ein Blogartikel, auf den man von der Landingpage aus zugreifen kann.

Im Fokus bei diesem Gruppenprojekt steht die Vertiefung von CSS Techniken, sowie das agile Arbeiten im Team mithilfe von Git und Github.
