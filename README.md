Dies ist ein Gruppenprojekt aus reinem HTML & CSS. Hierbei wird gemeinsam eine Landingpage anhand einer Figmavorlage erstellt und 
von jedem der Gruppenmitglieder zusätzlich noch einer Unterseite auf die man von der Landingpage aus zugreifen kann.

Im Fokus bei diesem Gruppenprojekt steht die Vertiefung von CSS Techniken, sowie das agile Arbeiten im Team mithilfe von Git und Github.
